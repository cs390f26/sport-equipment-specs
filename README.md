This repo contains the specification for a simple polling app that allows users to create a multiple-choice question (2–6 options), cast votes, and view results. We will deploy this application in a variety of ways using cloud technologies.

Use cases - Describes what users will experience with the running system. These cases form the basis for acceptance tests.
API - Describes the HTTP contract betwen the web brower (client) and the backend (server).
Data model - Describes how data is stored in a DynamoDB table.
Sample data - Example data show in DynamoDB format. These examples are codified in a machine-readable sample-data.json format for seeding a database and/or use with tests.
UI mocks This folder contains static HTML/CSS pages for the various views of the system.
